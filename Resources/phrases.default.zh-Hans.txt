# 碎碎念台词配置，修改后立即生效
# 一行一句，直接改字、加行、删行就行。`#` 是注释。
# 每句 30 字以内。
# 每个场景支持多行配置，如果一行都没有则不触发情景主动说话。
# 可以插进台词里的实时数据（连花括号一起写）：
#   {quota5h}    5 小时额度剩余，如 12%
#   {resetTime}  额度回血时间，如 18:30
#   {sessionMin} 本次已工作分钟数
#   {failCount}  连续失败次数
#   {toolName}   当前正在用的工具名，如 Bash
#   {hour}       当前小时，如 2
# 用了数据的句子，在拿不到该数据时会整条跳过。
